Система управления издательством

Описание проекта

Проект представляет собой объектно-ориентированную систему на языке C++ для автоматизации работы издательства. Программа моделирует ключевые бизнес-процессы издательской деятельности, включая управление каталогом печатной продукции, учет пользователей системы, оформление и обработку заказов, а также механизмы авторизации.

Архитектура и основные компоненты

Иерархия издательской продукции (Item): Базовый абстрактный класс, от которого наследуются конкретные виды публикаций: книги (Book), научные статьи (Article), журналы (Magazine) и пользовательские заказы печати (CustomItem). Поддерживается расчет стоимости, управление страницами и метаданными.
Иерархия пользователей (Person): Базовый класс для участников системы с поддержкой профилей, контактных данных и аутентификации через связанный модуль AuthorizationInfo (поддерживается регистрация, проверка логина и пароля, сеансы входа). На основе него реализованы специализированные роли:

Client — клиенты, управляющие балансом счета, совершающие депозиты и размещающие заказы.
Author — авторы, создающие новые литературные произведения и статьи.
Admin — администраторы, контролирующие выполнение заказов.

Управление издательством (Publisher): Центральный класс, агрегирующий каталог товаров, базы данных клиентов, авторов, администраторов и общую очередь заказов. Предоставляет методы поиска сущностей по идентификаторам и регистрации новых участников.

Генерация идентификаторов (IdGenerator): Шаблонный статический класс, реализующий автоматическое присвоение уникальных структурированных ID для различных типов сущностей (персонал, товары, заказы, издательства) с использованием механизмов проверки типов на этапе компиляции (is_base_of_v и if constexpr).

Требования к сборке

    Компилятор C++ с поддержкой стандарта C++17 или выше (используется std::is_base_of_v, std::make_unique).
    Стандартная библиотека C++ (STL)
